# Phase 19 route and security inventory

Generated from the real root Express registration tree using `node scripts/security-routes.cjs --markdown`. Capture disables `.env` loading, uses a disposable SQLite database and never opens a listener. Archived applications are not mounted by the active root server.

GET registrations also accept HEAD with identical authentication and authorization. All API responses are `no-store`. Browser mutations require JSON and a trusted Origin/Referer when supplied; cross-site Fetch Metadata is rejected without an allowed Origin. Safe reads do not require CSRF. CSRF is also enforced on public mutations when the relevant browser session already exists.

Role permissions are the server-side map in `lib/admin-security.cjs`. `admins.manage`, `users.promote` and `users.delete` are Super Admin-only; legacy user role updates also recheck Super Admin in the handler. Every administrative user mutation requires authentication within 15 minutes, including legacy PUT and DELETE. Async credential work rechecks the session before committing. Limits are configured guard budgets; namespace and route guards can both consume the same privileged budget for one request.

Static middleware and fallbacks:

| Surface | Policy |
| --- | --- |
| GET/HEAD `/css/*` | Exact stylesheet allowlist, extension and realpath checks; no directory listing. |
| GET/HEAD `/js/*` | Exact script allowlist and realpath checks. Five administration scripts require ADMIN/SUPER_ADMIN document authentication and no-store; admin-login.js is public. Express normalizes repeated mount separators before these same checks. |
| GET/HEAD `/img/*` | Image extensions only; dotfiles, traversal, backups, maps and realpath escapes denied. Existing SVGs use a sandboxed restrictive CSP. |
| `/admin.html`, `/admin.htm`, `/admin/index.html` | Denied with 404, including encoded aliases. `/admin` is the protected delivery route. |
| OPTIONS `/api/*` | Explicit-origin CORS preflight, no CSRF; global IP request limit still applies. |
| Unknown `/api/admin/*` | Namespace authentication and fail-closed permission checks precede fallback. |
| Unknown `/api/*` / public paths | JSON 404 / static escaped HTML 404; no arbitrary file access. |
| Legacy mutation aliases | `/api/products` POST/PUT/DELETE use the same admin session, permission, CSRF, revision and validation checks. `/api/admin/users/:id` PUT shares role/status hierarchy, recent-login and revocation logic. Disabled order-create/order-delete and admin user-create APIs return 405 after security checks. |
| Browser cart | Local browser state, no separate server cart API. Quotes and checkout validate trusted products and totals on the server. |
| Uploads and payments | No multipart upload/download endpoint or real payment callback/webhook exists. Admin artwork accepts validated image URLs or bounded signature-checked raster data; real payment mode fails closed. |
| Archived apps | `backend/`, `gaming-store/`, `gaming-ecommerce/` are separate inactive applications, excluded from release synchronization and public static roots; existing legacy security regressions remain in the suite. |
